# Validation Plan

## 1. Validation sequence

Validation has two distinct stages. Public Data Demo proves the technical and workflow slice; the later factory pilot proves operational value with real product assets. Passing the Demo does not by itself prove TikTok market performance or production readiness.

## 2. Public Data Demo validation

### Core question
Can a new user run the product workflow on public furniture data and produce a traceable, reviewable vertical marketing video without paid model credentials?

### Test path
Public SKU → source-backed facts → B2B/B2C brief → English script/storyboard → image/360° asset matching → edit decision list → MP4 render → QC → human review → content-pack export.

### Measure
- installation and first-run success
- time from SKU selection to output package
- percentage of storyboard shots matched or explicitly marked missing
- percentage of factual claims linked to source facts
- number of unsupported claims detected
- render success and technical QC pass rate
- reproducibility from the documented sample workflow

### Demo pass criteria
- clone/install/run instructions work in a clean environment
- at least one furniture SKU completes the full path
- no unknown attribute is silently inferred
- every used asset carries source and attribution metadata
- output MP4 is playable and labeled as image-based or 360°-based where applicable
- QC and human approval status are visible
- scripts, captions, subtitles, source manifest and quality report are exportable

## 3. Internal factory pilot validation (Phase 2)

### Core question
Can the same workflow reduce production effort while preserving product truth and creative quality when connected to authorized factory SKUs and real footage?

### Compare
Baseline: brief/script → footage capture → AI/manual editing → human review → TikTok publication.

Agent-assisted: SKU/facts → brief → script/storyboard → real footage matching → optional scene enhancement → deterministic render → QC → human review → publication.

### Measure
Efficiency: time to approved script, time to final video, human editing minutes and revision cycles.

Quality: factual errors, visual mismatch, English corrections, subtitle/audio issues and QC failure rate.

Marketing: views, retention/watch-time measures where available, engagement and qualified inquiries.

### Pilot pass criteria
No unapproved factual claims in released videos; every video traces to SKU and source assets; core QC is automated; operators can complete review and publishing; repeat production requires less repetitive work.

## 4. Failure priority

1. Product fact accuracy.
2. Visual fidelity.
3. Source footage quality and coverage.
4. English localization.
5. Hook and pacing.
6. Enhancement polish.

Do not optimize views at the expense of product accuracy or misleading claims.
