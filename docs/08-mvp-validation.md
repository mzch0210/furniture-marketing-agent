# MVP Validation Plan

## Core question
Can the Agent workflow reduce cost and turnaround time for furniture marketing videos without sacrificing product truth and creative quality?

## Compare
Baseline: script → footage capture → AI/manual editing → human review → TikTok publication.

Agent-assisted: SKU/facts → brief → script/storyboard → footage matching → optional enhancement → deterministic render → automated QC → human review → TikTok publication.

## Pilot
Start with a small set of real SKUs. For each, test several angles such as problem/solution, feature demonstration and lifestyle/use case. Keep approved product facts and source footage controlled where possible.

## Measure
Efficiency: time to approved script, time to final video, human editing minutes and revision cycles.
Quality: factual errors, visual mismatch, English corrections, subtitle/audio issues and QC failure rate.
Marketing: views, retention/watch time where available, engagement and qualified inquiries.

## Initial pass criteria
No unapproved factual claims in released videos; every video traces to SKU and source assets; core technical QC is automated; operators can review and publish; repeat production requires less repetitive work; multiple creative angles preserve product consistency.

## Failure priority
1. Product fact accuracy.
2. Visual fidelity.
3. Source footage quality/coverage.
4. English localization.
5. Hook and pacing.
6. Enhancement polish.

Do not optimize views at the expense of product accuracy or misleading claims.
