# Furniture Marketing Video Quality Standard

## 1. Default output profile

| Parameter | Initial default |
|---|---|
| Duration | 25–27 seconds; campaign-dependent |
| Canvas | 9:16 |
| Resolution | 1080×1920 |
| Frame rate | 30 fps |
| Container/codec | MP4 / H.264 |
| Language | English |
| Structure | Hook → Body → CTA |
| Shot plan | Around seven shot groups as a starting template |

These are internal production defaults, not universal platform requirements.

## 2. Two distinct media standards

### Public Data Demo

The Demo may use:
- catalog still images with pan/zoom and transitions
- public 360° turntable image sequences
- publicly licensed 3D renders, if provenance and rendering requirements are satisfied

Every output must identify its media basis. Image animation or a turntable sequence must not be described as factory-shot live-action footage. Do not synthesize missing product details.

### Production product

Real factory-approved product footage is the primary source. AI scene enhancement is auxiliary and must preserve product identity. A missing shot should produce a reshoot request rather than an invented demonstration.

## 3. Suggested story sequence

1. Hook: immediate use case, problem or compelling product view.
2. Product reveal: establish the actual SKU.
3. Feature: show only a source-backed feature.
4. Detail: material, construction or finish only when verified.
5. Use case: distinguish actual source footage from illustrative scene.
6. Proof: show demonstrable or approved evidence.
7. CTA: campaign-appropriate next action.

## 4. Product truth and visual fidelity

- Preserve product geometry, construction, color and finish.
- Do not add accessories or functions that are not included.
- Never invent dimensions, materials, load limits, certifications, guarantees or delivery commitments.
- Treat catalog claims as source-reported until independently/factory verified.
- If AI enhancement creates ambiguity, revert to the original asset or require human review.

## 5. Automated checks

Technical: file readability, duration, dimensions, FPS, codec, audio, subtitle presence, black-frame/frozen-frame detection and render completion.

Content: SKU match, asset provenance/license, claim-to-fact references, unverified-claim detection, source-type label, required CTA and subtitle/voice consistency.

## 6. Human review rubric

- Product truth and visual fidelity: 25
- English naturalness: 20
- Hook: 15
- Visual quality: 15
- Message clarity: 10
- Pacing: 10
- CTA: 5

Suggested internal decision: 85+ publishable; 75–84 revise; below 75 rework. Calibrate against pilot reviews; this is not an objective platform ranking.
